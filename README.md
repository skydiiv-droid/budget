# budget

현대카드·우리은행 **문자 알림**을 아이폰 단축어로 받아서 자동으로 분류하는 가계부.

아이폰은 다른 앱의 푸시 알림을 읽을 수 없어서(iOS에 해당 API가 없다), 카드사 앱
푸시 대신 **SMS**를 트리거로 쓴다. 수집·분류·저장은 Google Apps Script가 맡고,
데이터는 Google Sheets에 쌓인다. Mac도 Xcode도 필요 없다.

```
현대카드 / 우리은행 SMS
        ↓  아이폰 단축어 자동화 (즉시 실행)
   Apps Script  doPost()      수집 · 파싱 · 분류
        ↓
   Google Sheets              원장
        ↓  doGet()
   대시보드 (홈 화면에 추가)
```

## 설계 원칙

1. **원문은 버리지 않는다.** 들어온 문자를 `RawMessage`에 통째로 남긴다.
   파서를 고친 뒤 `reprocessAll()`로 과거 문자를 전부 다시 돌릴 수 있다.
2. **모든 쓰기는 멱등이다.** 같은 문자가 두 번 와도 `dedupeKey`로 걸러진다.
3. **파싱 실패는 에러가 아니다.** 실패해도 원문은 남고, 인박스에서 사람이 처리한다.

## 설정

1. 새 Google 스프레드시트를 만들고 **확장 프로그램 > Apps Script** 를 연다.
2. `npm run build` 로 만들어지는 `dist/budget-core.gs` 와 `dist/budget-parser.gs`
   두 파일을 Apps Script에 같은 이름으로 만들어 붙여넣는다.
   (편집만 한다면 `apps-script/` 의 원본을 고치고 다시 빌드한다)
3. **프로젝트 설정 > 스크립트 속성**에 `INGEST_TOKEN` 을 추가한다.
   값은 아무 긴 랜덤 문자열. 이 토큰이 유일한 방어선이다.
4. 편집기에서 `setup()` 을 한 번 실행한다. 시트와 초기 카테고리가 만들어진다.
5. **배포 > 새 배포 > 웹 앱** — 실행 주체 `나`, 액세스 권한 `모든 사용자`.
   나오는 URL을 복사한다.
6. 아이폰 단축어를 건다

처음 설정한다면 [docs/SETUP_WALKTHROUGH.md](docs/SETUP_WALKTHROUGH.md) 를 따라간다.
아이폰만으로 따라갈 수 있게 쪼개 뒀고, 1단계(수집)까지 15분이면 끝난다.

## 테스트

```sh
npm test
```

파서는 이 프로젝트에서 가장 잘 깨지는 부분이라 회귀 테스트를 붙여 뒀고,
빌드에서도 따로 떼어 둬서 고칠 때 262줄만 갈아끼우면 된다.
`tests/parser.test.js` 의 문자들은 **추정 포맷**이므로, 실제 수신 문자가 생기면
실물로 교체할 것.
