# 다음에 컴퓨터 앞에서 할 일

아이폰에서 하기 번거로워 미뤄 둔 것들. 위에서부터 순서대로 하면 된다.

## 1. 코드 갈아끼우기

Apps Script 편집기에서 두 파일을 교체한다.

| 파일 | 원본 |
|---|---|
| `budget-parser` | `dist/budget-parser.gs` |
| `budget-core` | `dist/budget-core.gs` |

좌측 파일 목록에 이 둘만 있어야 한다. `Code.gs` 가 남아 있으면 같은 함수가
두 벌이 되어 엉뚱하게 돈다.

## 2. `setup` 실행

분류 규칙 80여 개와 간편결제 대행사 목록이 새로 들어간다.
**이걸 건너뛰면 모든 거래가 미분류로 떨어진다.**

이미 있는 시트와 카테고리는 건드리지 않으므로 여러 번 실행해도 안전하다.

## 3. 재배포

> 배포 → 배포 관리 → ✏️ → 버전 **새 버전** → 배포

편집기에서 실행하는 것은 최신 코드지만, 아이폰에서 들어오는 요청은
**배포된 버전**으로 처리된다. 이걸 안 하면 아이폰 쪽은 옛 코드로 돈다.

## 4. `reprocessAll` 실행

그동안 파싱에 실패해 쌓여 있던 문자를 새 파서로 다시 읽고 거래까지 만든다.

```
훑은 문자 N건 · 이제 읽힘 N건 · 새로 만든 거래 N건
```

## 5. 시험용 데이터 지우기

`selfTest` 가 넣은 가짜 거래(우리은행 입금 10,000원 / 홍길동)를 지운다.
`Transaction` 과 `RawMessage` 시트에서 해당 행 삭제. 안 지우면 이번 달
수입에 1만원이 섞인다.

## 6. 아이폰 설정 두 가지 (폰에서)

- **잠겨 있을 때 실행 허용**
  단축어 → 가계부 수집 → ⌄ → 개인정보 보호 → 켜기
  이게 꺼져 있으면 주머니 속에서 일어난 결제를 대부분 놓친다.

- **현대카드 자동화 조건 확인**
  카드용과 은행용은 별개 자동화다. 문자 앱에서 현대카드 발신번호를 확인해
  조건과 대조한다. 번호가 여러 개면 `메시지에 포함` 에 `현대카드` 가 안전하다.

## 7. 확인

```
배포URL?token=토큰
```

거래 건수가 0이 아니고 미분류가 줄어 있으면 1단계 완료다.

## 8. 단축어에 분류 메뉴 붙이기

[SHORTCUT_SETUP.md](SHORTCUT_SETUP.md) 의 **기본형(액션 8개)** 부터.
서버가 메뉴를 만들어 보내므로 단축어는 `텍스트 나누기 → 목록에서 선택` 만 한다.

이게 2단계의 핵심이다. 수집만 되고 분류가 안 되면 미분류만 쌓이고,
한 달 뒤 예산을 잡으려 할 때 "배달에 얼마 썼는지"를 알 수 없다.
