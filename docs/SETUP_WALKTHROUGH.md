# 처음부터 끝까지 설정하기

아이폰만으로 할 수 있다. 1단계까지 마치면 그날부터 문자가 쌓인다.

문자 알림(현대카드·우리은행)은 이미 켜져 있다고 가정한다.

---

# 1단계 — 수집만 돌리기 (15분)

여기까지만 해도 "어디에 얼마 썼는지 모른다"는 문제가 풀린다.
분류·위치·더치페이는 2단계에서 얹는다.

## 1-1. 스프레드시트 만들기

1. 아이폰 Safari에서 **sheets.new** 접속 (구글 로그인 필요)
2. 빈 시트가 열린다. 이름을 `가계부` 로 바꾼다

> Safari에서 구글 시트가 앱으로 튕기면, 앱에서 나와 Safari 주소창에
> `sheets.google.com` 을 직접 치고 들어간다.

## 1-2. Apps Script 편집기 열기

1. Safari 하단 **⟨ᴀA⟩** 버튼 → **데스크탑 웹사이트 요청**
   (이걸 해야 메뉴가 보인다)
2. 상단 메뉴 **확장 프로그램 → Apps Script**
3. 새 탭에 편집기가 열린다. `Code.gs` 파일에 기본 코드가 몇 줄 있다

## 1-3. 코드 붙여넣기

파일 두 개를 만든다. 아이폰에서는 **긴 코드를 전체 선택해 지우는 게 고통스러우니,
기존 파일을 고치지 말고 새 파일을 만든 뒤 옛 파일을 지운다.**

새 파일에는 `function myFunction() {}` 세 줄만 들어 있어서 지우기 쉽다.

**① 파서 파일**
1. 좌측 `파일` 옆 **+ → 스크립트**
2. 이름을 `budget-parser` 로 한다
3. 안에 있는 세 줄을 지우고, [dist/budget-parser.gs](../dist/budget-parser.gs) 내용을 붙여넣는다

**② 코어 파일**
1. 같은 방법으로 **+ → 스크립트**, 이름 `budget-core`
2. [dist/budget-core.gs](../dist/budget-core.gs) 내용을 붙여넣는다

**③ 기본 파일 삭제**
1. `Code.gs` 파일명 옆 **⋮ → 삭제**
2. 좌측 상단 **저장**(💾)

> 앞으로 고칠 일이 잦은 건 파서뿐이다. 그때는 `budget-parser` 만 갈아끼우면 된다.
> 262줄이라 아이폰에서도 견딜 만하다.

**제대로 됐는지 확인**: 상단 함수 드롭다운에 `setup`, `checkSetup`, `selfTest` 가
모두 보이면 된다. 하나라도 없으면 붙여넣기가 덜 된 것이다.

## 1-4. 토큰 설정

이 토큰이 유일한 보안 장치다. 없으면 URL을 아는 누구나 네 시트에 쓸 수 있다.

1. 좌측 **⚙️ 프로젝트 설정**
2. 맨 아래 **스크립트 속성 → 스크립트 속성 추가**
3. 속성: `INGEST_TOKEN`
   값: 아무 긴 랜덤 문자열 (예: `bk7Qz2mXr9Lp4vT8wN3sD6`)
   → 꺾쇠나 따옴표 없이 값만 넣는다
4. **스크립트 속성 저장**
5. **이 값을 메모앱에 적어둔다.** 뒤에서 두 번 더 쓴다

## 1-5. 시트 만들기

1. 좌측 **⟨⟩ 편집기** 로 돌아온다
2. 상단 함수 드롭다운에서 **`setup`** 선택
3. **실행** 클릭
4. 권한 요청이 뜬다 → **권한 검토 → 계정 선택 → 고급 → (안전하지 않음) 이동 → 허용**
   (네가 방금 만든 스크립트라서 뜨는 경고다)
5. 실행 로그에 오류가 없으면 성공

시트 탭으로 돌아가면 `RawMessage`, `Transaction`, `Category` 등이 생겨 있다.
`Category` 시트에 카테고리 목록이 들어 있으면 제대로 된 것이다.

## 1-6. 웹앱 배포

1. 우측 상단 **배포 → 새 배포**
2. 톱니바퀴 ⚙️ → **웹 앱**
3. 설정
   - 설명: `가계부`
   - 실행 주체: **나**
   - 액세스 권한: **모든 사용자**
4. **배포**
5. 나오는 **웹 앱 URL** 을 복사해 메모앱에 적어둔다
   (`https://script.google.com/macros/s/AKfy.../exec` 형태)

> ⚠️ 코드를 고칠 때마다 **배포 → 배포 관리 → 편집(✏️) → 버전: 새 버전 → 배포**
> 를 해야 반영된다. URL은 그대로다.

## 1-7. 잘 됐는지 확인

배포 URL을 그대로 Safari 주소창에 친다. 토큰을 한 번 물어보고, 그 뒤로는
이 브라우저가 기억하므로 주소만으로 열린다.

```
https://script.google.com/macros/s/AKfycb.....무언가...../exec
```

토큰을 URL에 붙이고 싶다면 이렇게도 된다 (한 번 열면 저장된다).

```
https://script.google.com/macros/s/AKfycb.....무언가...../exec?token=bk7Qz2mXr9Lp4vT8wN3sD6
                                                              └──────────┬──────────┘
                                                              여기만 네 토큰으로 바꾼다
```

**`<` `>` 는 어디에도 들어가면 안 된다.** 이 문서에서 `웹앱URL`, `INGEST_TOKEN`
같은 말은 "네 값을 넣어라"는 뜻이지 그대로 적는 글자가 아니다.

`/exec` 와 `?token=` 사이에는 아무것도 없어야 한다. 꺾쇠가 끼면 `%3E` 로 바뀌어
경로가 깨지고 **"현재 파일을 열 수 없습니다"** 가 뜬다.

**수집 상태** 화면이 뜨면 성공이다. 전부 0건으로 나온다.

## 1-8. 단축어 만들기

단축어 앱 → **+** → 이름 `가계부 수집`

액션 하나만 넣는다. 검색창에 `url` 을 치고 **초록색 아이콘의
`URL 콘텐츠 가져오기`** 를 고른다. (`URL`, `URL 열기` 는 다른 액션이다)

추가하면 한 줄만 보인다. 아래 화살표(⌄)를 눌러 설정을 펼친다.

| 항목 | 값 |
|---|---|
| URL | 배포 URL — `/exec` 까지만. `?token=` 은 붙이지 않는다 |
| 방법 | `GET` 을 눌러 **POST** 로 바꾼다 |
| 요청 본문 | POST로 바꾸면 나타난다 → **JSON** |

> 주소창으로 대시보드를 볼 때만 `?token=` 을 쓴다.
> 단축어는 토큰을 본문 필드로 보내므로 URL에 붙이면 안 된다.

**본문 추가**를 눌러 필드 3개를 만든다:

| 키 | 타입 | 값 |
|---|---|---|
| `token` | 텍스트 | 네 토큰 값 (꺾쇠 없이) |
| `action` | 텍스트 | `ingest` |
| `body` | 텍스트 | **단축어 입력** ← 변수로 넣기 |

세 번째 값은 직접 타이핑하지 말고, 값 칸을 누른 뒤 키보드 위 변수 막대에서
**단축어 입력**을 고른다.

완료 → 저장.

## 1-9. 자동화 걸기

단축어 앱 → **자동화** 탭 → **+**

**카드용**
1. **메시지** 선택
2. **보낸 사람** — 문자 앱에서 현대카드 문자를 열어 발신번호를 확인해 넣는다
   (또는 **메시지에 포함** 에 `현대카드`)
3. **즉시 실행** 선택 (`실행 전 확인`이 꺼져야 한다)
4. 다음 → **가계부 수집** 선택

**은행용** — 같은 방식으로 하나 더. 조건은 우리은행 발신번호 (또는 `우리`)

## 1-9b. 잠금 상태에서도 돌게 하기

기본값으로는 **화면이 잠겨 있으면 자동화가 실행되지 않거나 잠금 해제 때까지 밀린다.**
결제는 대부분 폰이 주머니에 있을 때 일어나므로 이 설정이 없으면 대부분 놓친다.

```
단축어 앱 → 가계부 수집 → ⌄(세부사항) → 개인정보 보호
  → "잠겨 있을 때 실행 허용"  켜기
```

자동화 쪽도 **즉시 실행**이 켜져 있어야 한다.

이걸 켜도 100%는 아니다. iOS가 잠금 중 일부 동작을 막는 것은 보안 설계이고,
저전력 모드에서도 밀릴 수 있다. 문자 기반 수집의 구조적 약점이며,
잔액·누적 앵커를 둔 이유가 이것이다 — 몇 건이 새도 다음 문자에 찍힌 잔액과
앱 계산값의 차액으로 드러난다.

## 1-10. 진짜로 도는지 확인

편의점에서 아무거나 하나 사거나, 계좌에 1,000원을 이체해 본다.

문자가 오고 몇 초 뒤 1-7의 주소를 새로고침한다.
**받은 문자 1건**으로 늘어 있으면 성공이다.

시트의 `RawMessage` 탭에 문자 원문이 들어와 있다.

---

**여기까지가 1단계다.** 이제 아무것도 안 해도 문자가 자동으로 쌓인다.
`parsedOk` 열이 `FALSE` 여도 괜찮다 — 원문이 남았으면 나중에 전부 다시 읽는다.

며칠 두고 `RawMessage` 시트의 `body` 열을 복사해 넘기면, 실제 포맷에 맞춘
파서를 넣고 과거 문자까지 한 번에 다시 처리한다.

# 막혔을 때

## 먼저: 서버가 문제인지 아이폰이 문제인지 가른다

Apps Script 편집기에서 함수 목록의 **`checkSetup`** 을 실행한다.
빠진 설정이 있으면 무엇이 빠졌는지 로그에 찍힌다.

그다음 **`selfTest`** 를 실행한다. 가짜 문자 한 건을 직접 밀어 넣는다.

- **RawMessage가 늘어나면** → 서버는 멀쩡하다. 아이폰 단축어 쪽 문제다
- **늘어나지 않으면** → 서버 문제다. 로그에 찍힌 사유를 본다

## 단축어가 뭐라고 답했는지 보기

`URL 콘텐츠 가져오기` 아래에 **빠른 보기** 액션을 붙이고 단축어를 직접 실행한다.

| 응답 | 원인 |
|---|---|
| `{"status":"ignored","reason":"empty-body"}` | `body` 값이 변수 `단축어 입력` 이 아니라 그냥 글자다 |
| `{"status":"error","reason":"unauthorized"}` | 토큰이 스크립트 속성 값과 다르다 |
| 구글 로그인/오류 HTML 페이지 | 배포가 옛 버전이다 (아래) |
| `{"status":"parse_failed",...}` | 들어간 것이다. 대시보드를 새로고침한다 |

단축어를 손으로 실행하면 `단축어 입력`이 비어서 `empty-body`가 뜨는 게 정상이다.
그래도 서버까지는 닿았다는 뜻이므로 토큰과 배포는 문제없다는 확인이 된다.

## 코드를 바꿨는데 함수 목록이 그대로

붙여넣기가 덜 됐거나 옛 파일이 남아 있는 것이다. 좌측 파일 목록에
`budget-core`, `budget-parser` 둘만 있는지 확인한다. `Code.gs` 가 남아 있으면
같은 함수가 두 벌이 되어 엉뚱하게 돈다.

## 코드를 고쳤으면 반드시 재배포

**붙여넣기만 하고 재배포하지 않으면 옛 코드가 돈다.** 가장 흔한 원인이다.

> 배포 → **배포 관리** → ✏️ → 버전 **새 버전** → 배포

URL은 바뀌지 않으므로 단축어는 그대로 둬도 된다.

## 증상별

| 증상 | 확인할 것 |
|---|---|
| `unauthorized` 응답 | 단축어의 `token` 값과 스크립트 속성 `INGEST_TOKEN` 이 정확히 같은지 |
| 문자가 와도 안 쌓임 | 자동화가 **즉시 실행**인지 / 알림톡이 아니라 **문자**로 오는지 |
| 폰 쓸 때만 쌓임 | 세부사항 → 개인정보 보호 → **잠겨 있을 때 실행 허용** (1-9b) |
| 한쪽 카드/은행만 안 쌓임 | 자동화는 카드용·은행용이 별개다. 안 되는 쪽의 발신번호를 문자 앱에서 확인해 조건과 대조한다. 번호가 여러 개면 `메시지에 포함` 조건이 안전하다 |
| `시트 없음` 오류 | `setup()` 을 실행했는지 |
| 코드를 고쳤는데 그대로 | **새 버전**으로 재배포했는지 |
| 대시보드가 잠겨 있음 | 토큰을 넣으면 열린다. 이 브라우저가 기억한다 |
| `현재 파일을 열 수 없습니다` | 주소에 `<` `>` 가 섞였는지 (`%3E` 가 보이면 이것) |
| `현재 파일을 열 수 없습니다` | `/exec` 와 `?token=` 사이에 다른 글자가 없는지 |
