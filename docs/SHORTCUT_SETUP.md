# 단축어 — 2단계: 분류 메뉴 붙이기

1단계(수집)가 돌고 있다는 전제에서 시작한다. 아직이면
[SETUP_WALKTHROUGH.md](SETUP_WALKTHROUGH.md) 부터.

서버가 메뉴를 **줄바꿈으로 이어붙인 글자**로 보내준다. 단축어는 JSON을
헤집을 필요 없이 `텍스트 나누기 → 목록에서 선택` 만 하면 된다.
고른 글자를 그대로 되돌려주면 서버가 알아서 해석한다. id를 다룰 일이 없다.

---

## 서버가 보내는 것

자동 분류에 성공하면 `status: "categorized"` 만 온다. **아무것도 안 해도 된다.**
분류하지 못했을 때만 이런 게 함께 온다.

```json
{
  "status": "uncategorized",
  "txnId": "txn_...",
  "prompt": "우리동네김밥천국 23,000원",
  "menuText": "🛵 배달\n🍚 외식\n☕ 카페\n🛒 마트\n...",
  "scopeMenuText": "모두: 컴포즈\n이 가게만: 컴포즈커피발산\n이번만"
}
```

`menuText` 는 짚이는 카테고리가 앞에 오도록 서버가 정렬해 둔다.
위치 기록이 있으면 그게 첫 줄이다.

---

## 기본형 (액션 8개) — 이것부터

범위는 서버가 알아서 정한다. 아는 브랜드면 그 낱말로, 아니면 이름 그대로.

```
1. URL 콘텐츠 가져오기          ← 1단계에서 만든 것. 그대로 둔다
      본문: token / action=ingest / body=단축어 입력

2. 사전 값 가져오기
      사전: [1번의 URL 콘텐츠]      키: status

3. 만약  [2번 결과]  가  uncategorized  이면
   │
   ├ 4. 사전 값 가져오기   사전:[1번]  키: menuText
   │
   ├ 5. 텍스트 나누기      텍스트:[4번]  구분자: 새로운 줄
   │
   ├ 6. 목록에서 선택      목록:[5번]
   │        프롬프트: [사전 값 가져오기 → prompt]  (생략 가능)
   │
   ├ 7. URL 콘텐츠 가져오기
   │        URL    : 같은 배포 URL
   │        메소드 : POST      본문 요청: JSON
   │        token  : 네 토큰
   │        action : categorize
   │        txnId  : [사전 값 가져오기 → 사전:[1번] 키:txnId]
   │        choice : [6번에서 고른 것]
   │
   └ 8. 알림 표시
            [사전 값 가져오기 → 사전:[7번] 키: message]
   종료
```

8번 알림에는 이렇게 뜬다.

```
카페(으)로 저장 · 앞으로 「컴포즈」는 자동 · 밀려 있던 2건도 정리
```

### 만드는 요령

- **`만약`** 은 액션 검색에서 `만약` 으로 찾는다. `종료` 는 자동으로 붙는다
- **[1번의 URL 콘텐츠]** 를 나중 단계에서 고를 때는, 값 칸을 누르고 변수 막대에서
  `URL 콘텐츠` 를 고른다. 같은 이름이 여러 개면 순서대로 1번·7번 것이다
- 7번은 1번 액션을 **복제**해서 본문 필드만 고치는 게 빠르다
  (액션 길게 눌러 `복제`)

## 확장형 (+3개) — 범위까지 직접 고르기

프랜차이즈 지점명 때문에 범위를 매번 정하고 싶으면, 6번과 7번 사이에 넣는다.

```
6-1. 사전 값 가져오기   사전:[1번]  키: scopeMenuText
6-2. 텍스트 나누기      구분자: 새로운 줄
6-3. 목록에서 선택      프롬프트: 앞으로 어디까지?

7.   URL 콘텐츠 가져오기 ... 본문에 필드 하나 추가
         scopeChoice : [6-3에서 고른 것]
```

범위 메뉴는 이렇게 뜬다.

| 고르는 것 | 뜻 |
|---|---|
| `모두: 컴포즈` | 그 낱말이 들어간 모든 가맹점 |
| `이 가게만: 컴포즈커피발산` | 이름이 똑같은 곳만 |
| `이번만` | 규칙을 만들지 않음 |

짚이는 브랜드가 없으면 `모두:` 줄은 아예 안 나온다. 고를 수 없는 선택지를
띄우지 않기 위해서다.

---

## 위치 붙이기 (선택)

1번 액션 **앞에** `현재 위치 가져오기` 를 넣고, 1번 본문에 필드를 둘 추가한다.

```
lat : [현재 위치 → 위도]
lon : [현재 위치 → 경도]
```

설정 → 개인정보 보호 → 위치 서비스 → **단축어 → 항상**.
"앱을 사용하는 동안" 이면 백그라운드에서 좌표를 못 가져온다.

간편결제(`네이버파이낸셜`)는 이름으로 분류할 수 없는데, 같은 자리에서 세 번
이상 같은 카테고리를 골랐으면 좌표로 자동 분류된다.

좌표는 네 구글 드라이브의 시트에 쌓인다. 동선 기록이 남는다는 뜻이므로
원치 않으면 이 액션만 빼면 된다.

---

## 알림이 너무 자주 뜨면

분류에 성공한 건은 원래 알림이 안 뜬다. 그래도 잦다면 규칙이 덜 쌓인 것이다.
편집기에서 `listRules()` 로 지금 걸린 규칙을 보고,
자주 가는 곳이 빠져 있으면 다음에 물어볼 때 `모두:` 로 골라 둔다.

잘못 만든 규칙은 `forgetRule({pattern: '동네빵집'})` 로 지운다.
