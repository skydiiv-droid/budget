# 아이폰 단축어 설정

## 1. 카드사·은행 문자 알림 켜기

| | 신청 | 비고 |
|---|---|---|
| 현대카드 | 앱 > 카드 관리 > 카드이용알림 > **문자** | 월 300원. **5만원 이상만 무료** 옵션은 고르지 말 것 — 소액이 전부 누락된다 |
| 우리은행 | 입출금 알림 **문자** | 잔액 표기 켜기 |

⚠️ **카카오 알림톡으로 받으면 안 된다.** 알림톡은 문자가 아니라 카톡 앱 푸시라서
단축어 트리거가 안 걸린다. 반드시 SMS/LMS여야 한다.

현대카드는 **누적 사용금액 표기**도 켜 둔다. 월 기준 누적이라 사이클(1일~말일)과
경계가 맞아서, 앱이 계산한 합계와 대조해 누락을 자동으로 잡을 수 있다.

## 2. 수집 단축어 만들기

단축어 앱 > 새 단축어. 이름: `가계부 수집`

```
1. URL의 내용 가져오기
     URL      : <웹 앱 배포 URL>
     방식     : POST
     본문     : JSON
       token      : <INGEST_TOKEN>
       action     : ingest
       body       : [단축어 입력]        ← 문자 본문
       sender     : (비워도 됨)
     헤더     : Content-Type = application/json

2. 사전 설정 (If)  —  "URL의 내용 가져오기" 의 status 값
     status 가 uncategorized 이면
       3. 메뉴에서 선택
            [suggestions 1] [suggestions 2] [suggestions 3] [직접 입력] [나중에]
       4. 선택 결과로 다시 URL의 내용 가져오기
            action     : categorize
            txnId      : 1번 응답의 txnId
            categoryId : 고른 카테고리 id
     그 외 (categorized / ignored / duplicate)
       아무것도 하지 않음          ← 알림 0개. 이게 핵심이다
```

자동 분류에 성공하면 **알림이 뜨지 않는다.** 조용히 기록된다.
하루 8건 결제해도 실제로 뜨는 알림은 1~3개로 유지된다.

## 3. 자동화 걸기

단축어 앱 > **자동화** > 새 자동화 > **메시지**

- 보낸 사람: 현대카드 발신번호 / 우리은행 발신번호 (문자 앱에서 확인)
- 또는 "메시지에 포함": `현대카드`, `우리`
- **실행 전 확인: 끄기** ← 이걸 꺼야 백그라운드로 조용히 돌아간다
- 동작: `가계부 수집` 실행

카드용·은행용으로 자동화를 **두 개** 만든다.

## 4. 대시보드 홈 화면에 추가

Safari에서 `<웹 앱 URL>?token=<INGEST_TOKEN>` 을 열고
공유 > 홈 화면에 추가. 아이콘이 생기고 주소창 없이 앱처럼 열린다.

## 알아둘 것

자동화는 **에러 없이 조용히 멈출 때가 있다.** 재부팅 직후, 저전력 모드,
iOS 업데이트 후 권한 리셋 등.

그래서 대시보드에 "마지막 수신 시각"을 띄워 둔다. 하루 이상 비어 있으면
자동화를 다시 확인할 것. 잔액 앵커가 붙은 뒤에는 차액으로도 티가 난다.
