# 위젯 — 잠금화면에서 보기

웹앱은 진짜 iOS 위젯을 못 만든다. **Scriptable**(무료 앱)이 그걸 대신한다.
읽기 전용 창구를 하나 두고, Scriptable 이 거기서 숫자 몇 개를 받아다 그린다.

넣는 건 두 개다.

| 파일 | 하는 일 |
|---|---|
| `widget/budget-widget.js` | 잠금화면·홈 화면 위젯 |
| `widget/budget-alert.js`  | 카드값 빠지기 전 알림 |

---

## 1. 위젯 비밀번호를 정한다

웹앱 → **설정 → 문자 연결 → 위젯 비밀번호**.

문자를 넣는 비밀번호와 **다른 걸** 쓴다. 넣는 쪽이 읽기까지 되면
단축어 설정 하나가 새는 것과 가계부 전체가 새는 것이 같은 일이 되기 때문이다.

이 비밀번호로 읽히는 건 **합계 몇 개뿐**이다 — 이 달에 쓴 돈, 오늘 쓸 수 있는 돈,
다음 카드값, 목표 진행률. 어디서 얼마 썼는지는 안 나간다.

## 2. Scriptable 에 스크립트를 넣는다

1. App Store 에서 **Scriptable** 설치
2. 앱을 열고 오른쪽 위 **＋**
3. `widget/budget-widget.js` 내용을 통째로 붙여 넣기
4. 맨 위 `TOKEN` 을 방금 정한 위젯 비밀번호로 바꾸기

   ```js
   const TOKEN = '여기에-위젯-비밀번호';   // ← 이 줄만 고치면 된다
   ```

5. 이름을 `가계부` 로 바꾸고 나가기
6. 한 번 실행해서 숫자가 뜨는지 확인 (아래 ▶︎ 버튼)

## 3. 위젯을 얹는다

**잠금화면** — 잠금화면 길게 누르기 → 사용자화 → 잠금화면 → 시계 아래 칸 →
Scriptable → 위젯 고르기에서 `가계부`

- **한 줄(인라인)** — `오늘 ₩12,400 · 11일`
- **원형** — 소진율 게이지
- **네모** — 오늘 쓸 수 있는 돈 + 진행

**홈 화면** — 빈 곳 길게 누르기 → ＋ → Scriptable → 크기 고르기

- **작게** — 오늘 쓸 수 있는 돈, 예산 막대, 정리할 건수
- **중간** — 거기에 다음 카드값과 지난달 견줌까지

> 잠금화면 위젯은 카드 긁기 직전에 눈에 들어온다. 그게 이 위젯의 전부다.

## 4. 알림 (선택)

`widget/budget-alert.js` 도 같은 방법으로 Scriptable 에 넣고 `TOKEN` 을 바꾼다.
이름은 `가계부 알림`.

그다음 **단축어** 앱에서:

1. **자동화** 탭 → **＋** → **시간대**
2. **매일**, 오전 9시, **즉시 실행** 켜기
3. 동작 추가 → `Scriptable` → **스크립트 실행** → `가계부 알림`

알릴 게 있을 때만 뜬다.

- 카드값 빠지기 **2일 전**부터
- 생활비 예산을 다 썼을 때
- 이 속도면 예산을 15% 넘길 때

매일 오는 알림은 며칠이면 안 보게 되므로, 없으면 아무것도 안 띄운다.

## 주소가 바뀌었을 때

함수를 다시 배포해도 주소는 그대로다. 혹시 바뀌면 두 스크립트의 `URL` 을 고친다.
지금 주소는 배포 로그의 **주소** 단계에 찍힌다.

```js
const URL = 'https://summary-6ygn4mmscq-du.a.run.app';
```

## 안 될 때

| 화면에 뜨는 말 | 뜻 |
|---|---|
| `토큰이 맞지 않습니다` | 스크립트의 `TOKEN` 과 앱 설정의 값이 다르다 |
| `앱 설정에서 위젯 비밀번호를 정해 주세요` | 1번을 안 했다 |
| `앱에 한 번 로그인해 주세요` | 웹앱에 구글 로그인을 한 번도 안 했다 |
| 아무것도 안 뜸 | 위젯을 길게 눌러 **위젯 편집 → 스크립트**가 맞는지 확인 |

iOS 가 위젯을 언제 새로 그릴지는 iOS 가 정한다. 20분마다 다시 그리라고
적어 두었지만 그대로 되지는 않는다. 위젯을 눌러 앱을 열었다 나오면 대개 갱신된다.
